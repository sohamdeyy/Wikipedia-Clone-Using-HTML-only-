# Wikipedia-Clone-Using-HTML-only-

A **Wikipedia Clone** is a web application that replicates the core functionality and user interface of the Wikipedia website. It allows users to search, view, and read articles in a format similar to Wikipedia, providing a clean layout and responsive design.

This project is built using modern web technologies such as **HTML, CSS, JavaScript, and optionally backend frameworks**, to simulate real-world web development and API integration. The clone may use the official Wikipedia API to fetch live article data and display search results dynamically.

### Features

* Search functionality to find articles
* Display article title, summary, and content
* Responsive Wikipedia-like UI
* Navigation between articles
* Dynamic data fetching using Wikipedia API (optional)
* Clean and user-friendly design

### Technologies Used

* HTML5
* CSS3
* JavaScript
* REST API (Wikipedia API)
* Optional: React / Node.js / Express / MongoDB

### Purpose of the Project

* Practice frontend and full-stack development
* Learn API integration
* Understand real-world website architecture
* Improve UI/UX development skills
